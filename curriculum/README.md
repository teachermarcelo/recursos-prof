# FLUENT IMMERSION — CEFR Curriculum

Esta pasta organiza a progressão curricular por nível. Cada nível deve conter unidades, objetivos comunicativos, descritores CEFR relevantes, vocabulário, funções linguísticas, evidências de aprendizagem e links para os kits correspondentes.

## Níveis
- A0 — Beginner Foundations (etapa curricular introdutória pré-A1; não é nível oficial independente do CEFR)
- A1 — Elementary
- A2 — Pre-Intermediate
- B1 — Intermediate
- B2 — Upper-Intermediate
- C1 — Advanced
- C2 — Proficiency

Cada aula deve ter um código único e usar os componentes definidos em `lesson-kits/`. O currículo não deve ser tratado como uma sequência oficial prescrita pelo CEFR; a sequência pedagógica é uma proposta FLUENT IMMERSION que deve ser revisada.
