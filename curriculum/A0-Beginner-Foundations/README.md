## Estrutura recomendada
- `units/UNIT01/`: plano da unidade e mapa de aulas.
- Cada aula recebe um código único, por exemplo `A0-UNIT01-LESSON001`.
- Os materiais-fonte e checklists ficam em `lesson-kits/`; esta pasta mantém o mapa curricular e links para as aulas.
