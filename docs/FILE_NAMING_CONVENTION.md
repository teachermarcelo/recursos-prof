# File Naming Convention

Use `[LEVEL]-UNIT[NN]-LESSON[NNN]-[COMPONENT]-v[MAJOR.MINOR].[ext]`.

Examples:
- `A1-UNIT01-LESSON001-01-OVERVIEW-v1.0.docx`
- `A1-UNIT01-LESSON001-02-TEACHERS-GUIDE-v1.0.docx`
- `A1-UNIT01-LESSON001-05-PRESENTATION-v1.0.pptx`
- `A1-UNIT01-LESSON001-15-PROGRESS-TRACKER-v1.0.xlsx`
- `A1-UNIT01-LESSON001-18-QUALITY-ASSURANCE-v1.0.pdf`

Use stable component numbers 01–18 across all lessons. Keep editable source files distinct from published final files.
